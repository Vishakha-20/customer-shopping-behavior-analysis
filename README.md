# Retail Customer Insights

An end-to-end customer shopping behavior analysis project using Python, SQL, and Power BI. This project explores retail customer data to understand purchasing patterns, customer segments, and shopping trends.

> **Project attribution:** This portfolio project is based on the work of [Amlan Mohanty](https://github.com/amlanmohanty1/customer-trends-data-analysis-SQL-Python-PowerBI). The original creator's work is acknowledged here.

## Project Objectives

- Explore and prepare customer shopping data using Python.
- Perform exploratory data analysis (EDA) to understand the dataset.
- Use SQL queries to investigate customer purchasing behavior.
- Build an interactive Power BI dashboard to visualize shopping trends.
- Summarize findings and potential business recommendations.

## Tools and Technologies

- **Python:** Data exploration, cleaning, and preparation
- **SQL:** Querying data and answering business questions
- **Power BI:** Interactive dashboards and data visualization
- **Jupyter Notebook:** Executing and documenting Python analysis

## Project Workflow

1. **Business Problem:** Understand the retail analysis objectives.
2. **Python Analysis:** Import, clean, prepare, and explore the data.
3. **SQL Analysis:** Investigate customer and purchasing patterns.
4. **Power BI Dashboard:** Visualize key metrics and trends.
5. **Reporting:** Document findings and possible business implications.
6. **Presentation:** Organize the project findings for communication.
7. **GitHub:** Maintain project files and documentation.
